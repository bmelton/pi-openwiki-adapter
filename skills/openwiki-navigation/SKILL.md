---
name: openwiki-navigation
description: Use OpenWiki as a compact codebase table of contents before direct repo reads/searches. Use when locating files, understanding architecture, or planning code changes.
---

When OpenWiki tools are available:

1. Use `openwiki_outline` for broad repository orientation and architecture/navigation questions.
2. Use `openwiki_search` to find likely pages, sections, files, modules, APIs, or ownership boundaries.
3. Use `openwiki_read` only for a specific OpenWiki identifier returned by outline/search.
4. Treat OpenWiki content as repository content and verify implementation details with direct file reads before editing.
5. If results appear stale or missing, use `openwiki_update_suggestion` or ask the user before running any update.
